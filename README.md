# Sensory

Herramientas abiertas y gratuitas para que los negocios locales (bares, peluquerías, talleres, clínicas, tiendas) tengan presencia digital sin pagar licencias, con funciones de IA en camino.

Proyecto de **Sensory Ideas**, hecho desde Benidorm.

## Qué hay ahora

### Creador de webs para negocios locales
Rellenas nombre, sector, servicios, dirección, teléfono y horario, y genera al momento una web de una página lista para publicar: botón de WhatsApp, enlace a Google Maps, llamada directa, adaptada a móvil y con el color de la marca.

- Sin instalar nada: abre `index.html` en el navegador.
- Descarga la web como un único archivo `.html` y súbela a cualquier hosting gratuito (GitHub Pages, Netlify, Vercel).
